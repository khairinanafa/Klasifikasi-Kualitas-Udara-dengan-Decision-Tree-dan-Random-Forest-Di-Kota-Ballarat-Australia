# 🌫️ Klasifikasi Kualitas Udara di Kota Ballarat

## 📌 Deskripsi

Proyek ini membahas **klasifikasi kualitas udara di Kota Ballarat, Australia** menggunakan dua metode Machine Learning, yaitu:

* Decision Tree
* Random Forest

Kedua metode digunakan untuk melakukan klasifikasi dan kemudian dibandingkan berdasarkan performanya.

## 🎯 Tujuan

Tujuan proyek ini adalah:

1. Melakukan preprocessing terhadap data kualitas udara.
2. Menganalisis karakteristik dataset.
3. Membangun model Decision Tree.
4. Membangun model Random Forest.
5. Membandingkan performa kedua metode.
6. Menentukan metode yang memberikan performa klasifikasi yang lebih baik.

## 🗂️ Dataset

Dataset yang digunakan:

```text
air-quality-observations.csv
```

Dataset berisi data pengamatan kualitas udara di Kota Ballarat.

## 🔄 Tahapan Analisis

### 1. Data Preparation

Data dipersiapkan agar dapat digunakan dalam proses analisis dan pemodelan.

### 2. Exploratory Data Analysis

Dilakukan eksplorasi untuk memahami karakteristik data dan hubungan antarvariabel.

### 3. Decision Tree

Model Decision Tree digunakan untuk melakukan klasifikasi kualitas udara berdasarkan variabel yang tersedia.

### 4. Random Forest

Random Forest digunakan sebagai metode pembanding.

Random Forest merupakan metode ensemble yang menggabungkan beberapa Decision Tree untuk menghasilkan prediksi.

### 5. Perbandingan Model

Performa Decision Tree dan Random Forest dibandingkan untuk mengetahui metode yang memberikan hasil klasifikasi lebih baik.
